# /public folder

Put your static assets here. They are served from the root URL.

## Your profile photo:
- Save your photo as: `profile.jpg` (or profile.png / profile.webp)
- Place it in THIS folder: brandon-portfolio/public/profile.jpg
- It will be accessible at: http://localhost:5173/profile.jpg

## Other assets you can add here:
- CV PDF:     public/cv.pdf          → accessible at /cv.pdf
- OG image:   public/og-image.png    → for social media previews
- Any images used in the site

## DO NOT put JavaScript or React components here.
## React source code goes in /src
